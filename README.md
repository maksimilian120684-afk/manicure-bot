# Бот записи для Facebook Messenger

Что умеет: приветствие и меню, «Услуги и цены», «Адрес и часы», запись клиента (услуга → день → время → имя и телефон → подтверждение). Записи сохраняются в `bookings.json`, владельцу можно присылать уведомление (`OWNER_PSID`).

Данные салона (название, адрес, услуги, цены) правятся ТОЛЬКО в `config.js`.

## Переменные окружения (секреты хранятся только здесь, не в коде и не в чате)
| Имя | Что это |
|---|---|
| PAGE_ACCESS_TOKEN | токен страницы из блока 2 «Сгенерируйте маркеры доступа» |
| VERIFY_TOKEN | любая строка, которую вы придумаете (например `manicure123`); её же вставите в Meta |
| APP_SECRET | секрет приложения (Настройки приложения → Основные) |
| GOOGLE_SERVICE_ACCOUNT | (для календаря) весь JSON-ключ сервисного аккаунта Google, вставляется целиком |
| GOOGLE_CALENDAR_ID | (для календаря) ID календаря салона |

## Запуск на Render (бесплатно)
1. Создайте аккаунт на https://github.com и новый **приватный** репозиторий, загрузите в него файлы проекта (без `node_modules`).
2. На https://render.com: New → Web Service → подключите репозиторий.
3. Настройки: Runtime `Node`, Build Command `npm install`, Start Command `npm start`, тариф Free.
4. В разделе Environment добавьте три переменные из таблицы выше.
5. После деплоя Render покажет адрес вида `https://имя.onrender.com`. Проверка: откройте его в браузере, должно быть «Манекюр Тест: бот работает».

## Подключение к Meta
1. developers.facebook.com → ваше приложение → Сценарии использования → Настроить → «Настройки Messenger API».
2. Блок 1 «Настройте Webhooks»:
   - URL обратного вызова: `https://имя.onrender.com/webhook`
   - Подтверждение маркера: ваш `VERIFY_TOKEN`
   - «Подтвердить и сохранить».
3. Блок 2: напротив страницы «Добавить подписки», отметьте `messages` и `messaging_postbacks`, сохраните.
4. Напишите странице «Манекюр Тест» в Messenger со своего аккаунта: бот должен ответить меню.

## Важно
- Пока приложение не опубликовано (режим разработки), бот отвечает только людям с ролью в приложении (админ, разработчик, тестировщик).
- На бесплатном Render сервис «засыпает» после простоя, первый ответ может прийти с задержкой ~30–60 секунд, а `bookings.json` может стираться при перезапуске. Для реальных клиентов нужен платный тариф или база данных.
- Для работы с чужими клиентами приложению потребуется проверка Meta (App Review, разрешение `pages_messaging`).

## Календарь Google (выбор свободного времени клиентом)
Если заданы `GOOGLE_SERVICE_ACCOUNT` и `GOOGLE_CALENDAR_ID`, бот предлагает клиенту только свободные дни и время и сам создаёт событие в календаре. Без них работает простая запись текстом.

Для хозяйки салона: открывает свой Google Календарь на телефоне.
- Больничный/выходной/перерыв: создайте событие «Занято» на нужные часы или на весь день, бот не будет предлагать это время.
- Кто придёт завтра: откройте завтрашний день, там события «Услуга — Имя телефон».
- Перенос или отмена записи: переместите или удалите событие.

Настройки времени (часы работы по дням, длительность услуг, шаг записи, на сколько дней вперёд) правятся в `config.js`.

Подключение нового салона: хозяйка открывает доступ к своему календарю (Настройки календаря → Доступ для отдельных пользователей) на адрес сервисного аккаунта из JSON-ключа (`client_email`) с правом «Вносить изменения в мероприятия» и присылает ID календаря (Настройки календаря → Интеграция календаря).
